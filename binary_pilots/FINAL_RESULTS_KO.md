1. 새 이슈 20개 추가 실행
최초 예비 표본과 겹치지 않는 이슈 20개(공식 해결 10개·미해결 10개)를 새로 동결하고, Agentless와 개발자 패치 각 20개를 세 방식으로 평가했다. 추가 실행만 120건의 실제 판정이다. 전체 두 실행은 서로 다른 이슈 40개·패치 80개·판정 240건이며, 루브릭 생성 40건까지 합쳐 모델 호출 280건이다. 모델은 모두 같은 Qwen2.5-Coder-7B-Instruct의 고정 revision이다.
두 번째 실행은 첫 번째의 형식 문제를 본 뒤 설계한 후속 예비 실험이다. 판정 프롬프트는 유지했고 새 표본과 형식 파싱 규칙을 새 판정 전에 고정했다. 우월성 검정이나 완전한 시스템 재현이 아니다.

(비교표는 위에 표시함)

표의 분모는 유효 응답이다. 실패를 거절로 대체하지 않았다. Agent 기능 일치는 과거 공식 resolved 결과와의 일치이며, 새 테스트 실행이나 사람 mergeability 정확도가 아니다. 개발자 패치는 새로 테스트한 정답으로 간주하지 않고 승인율을 따로 표시했다.

2. 최초 예비 실행과 형식 오류
최초 120개 판정 가운데 37개는 JSON 앞뒤에 Markdown 코드 블록 표시가 있어 사전에 동결한 엄격한 파서에서 실패했다. 원시 응답·엄격한 판정·원래 분석은 그대로 보존했다. 사후에 코드 블록 표시만 제거하고 내부 JSON을 동일하게 검사한 보조 분석을 추가했으며, 판정 값·이유의 의미는 변경하지 않았다. 이 보조 분석을 최초의 사전 정의 결과로 바꾸지 않는다.
• ICSE 적응 방식: 최초 엄격 파싱 유효 29/40, 형식 실패 11건. 형식만 정리한 사후 보조 분석의 Agent 기능 일치 14/20, 개발자 패치 승인 13/20.
• Cihan binary 적응: 최초 엄격 파싱 유효 15/40, 형식 실패 25건. 형식만 정리한 사후 보조 분석의 Agent 기능 일치 15/20, 개발자 패치 승인 12/20.
• Shi draft-rubric 적응: 최초 엄격 파싱 유효 39/40, 형식 실패 1건. 형식만 정리한 사후 보조 분석의 Agent 기능 일치 14/20, 개발자 패치 승인 15/20.

추가 실행 v2의 파서는 응답 전체를 감싼 하나의 json 코드 블록만 허용한다. 임의의 본문에서 JSON을 추출하거나 라벨을 바꾸거나 실패 응답을 거절로 간주하지 않는다. 이 규칙은 v2 판정 전에 고정했다. 최초 예비 결과와 후속 결과의 표본·파싱 차이를 숨겨 합산한 주결과는 제시하지 않는다.

3. 비교 가능한 범위와 미완료 사항
공통 조건: 후보와 이슈, 고정 모델, greedy decoding, 공통 ACCEPT/REJECT JSON 출력, 테스트 결과를 알려주지 않는 조건이다. 후보의 출처·공식 해결 여부는 판정 프롬프트에서 가렸다.
• Cihan: 공개 Zenodo 패키지에서 설명 포함 조건의 기능·edge case·변경 필요성 판단을 가져왔다. HumanEval 함수 대신 diff를 넣고 수정 코드 생성은 제외했다. 원래 GPT-4o/Gemini 시스템이나 correction/regression 실험 전체의 재현은 아니다.
• Shi: 이슈·개발자 패치에서 버그별 draft rubric을 생성해 판정했다. 원 논문의 미수정 루브릭 ablation을 적응했다. 실제 개발자 두 사람의 수정·확인, golden rubric, 사람 합의 patch 라벨은 아직 없다. human-in-the-loop 전체 완료라고 쓰면 안 된다.
• ICSE: 기존 calibrated maintainer 기준에서 잘못된 테스트 통과 안내를 제거하고 공통 binary 출력으로 적응했다. 기존 원고의 과거 instrument를 바꾸지 않고 그대로 재현했다고 주장하지 않는다.
Shi는 루브릭을 통해 개발자 패치를 보는 추가 정보와 호출 비용이 있다. 다른 두 방식은 그 reference를 보지 않는다. 정보량까지 같은 인과적 비교가 아니며, 개발자 패치 승인에는 reference bias가 있다. 표본이 작고 신뢰구간이 넓으며 기능 결과는 mergeability truth가 아니므로 방법의 우열이나 사람 리뷰 일치도를 결론내리지 않는다.
이 실험은 proceedings 모든 권·호·쪽수의 서지 검증을 완료한 것도 아니다. 두 원문은 version이 고정된 preprint로 식별하고, Cihan의 공개 재현 패키지를 별도 확보했다.
